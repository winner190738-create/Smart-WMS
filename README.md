# Smart Warehouse Management System (Prototype)

Frontend prototype สำหรับจัดการคลังสินค้า พัฒนาด้วย HTML, Bootstrap 5, CSS และ JavaScript เท่านั้น

## การใช้งาน

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ได้ทันที โดยไม่ต้องติดตั้ง Node.js, Express, MySQL หรือฐานข้อมูลใด ๆ

## ฟีเจอร์

- Login (จำลอง)
- Dashboard สรุปคลังและรายการเคลื่อนไหว
- เพิ่ม ค้นหา และแก้ไขสินค้า
- รับสินค้าเข้าและจ่ายสินค้าออก พร้อมอัปเดตสต็อกใน JavaScript Array
- รายงานสินค้าคงเหลือและส่งออกเป็น CSV

ข้อมูลจะอยู่ในหน่วยความจำของเบราว์เซอร์และจะกลับเป็นค่าเริ่มต้นเมื่อรีเฟรชหน้าเว็บ
